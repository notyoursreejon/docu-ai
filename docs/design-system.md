# DocuAI Design System

## Typography
- **Font**: Inter (or Geist). Clean, modern sans-serif.
- **Headings**: Large display headings, tight tracking.
- **Body**: 16px base size for readability.

## Colors
- **Primary**: Deep Blue/Purple for high contrast.
- **Background**: 
  - Light mode: Pure white (`#ffffff`) to soft gray (`#f8fafc`).
  - Dark mode: Deep gray/black (`#09090b`).
- **Surface**: Subtle borders (`#e2e8f0` in light, `#27272a` in dark).

## UI Components (shadcn/ui)
- **Cards**: 12-16px border radius, subtle shadows.
- **Buttons**: Fully rounded or slight radius, smooth hover transitions.
- **Inputs**: Clean borders, distinct focus rings.
- **Modals/Dialogs**: Glassmorphism backdrop, solid surface.

## Animations
- Framer Motion for page transitions, dialog openings, and the landing page OCR visualization.
- Respect `prefers-reduced-motion`.
